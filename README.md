# 預支款申請單列印工具

依據原始 Word 預支款申請單製作的靜態網站，可線上填寫、即時預覽，並在空白 A4 紙列印完整文字、表格與勾選內容。無圖片底圖，無伺服器或外部服務依賴。

## 功能

- 單位、收件日期、請款日期、用途說明。
- 專案活動預算表、簽呈編號、合約書可複選，並填寫文件編號或補充說明。
- 匯率、幣別、暫借金額，金額自動拆入八位整數及角、分共十格。
- 金額範圍 0 至 99,999,999.99，以整數分計算，避免角分浮點加總誤差；匯率供填寫，不自動換算。
- 現金、匯款、開票、銀行本票可複選，各自填金額。台幣時檢查付款合計是否與暫借金額相同；不一致會提示，仍可保存或列印。
- 匯款選項下直接展開收款銀行、銀行代號、帳號及戶名；代號與帳號保留開頭的 0。
- 選開票或銀行本票時可填廠商、到期日及支票抬頭。
- 預定支用日期、預定沖銷日期；日期輸入西元，列印民國年。
- 核銷憑證可複選：發票、購票證明、普通收據、領據、其他及其他說明。
- 備註、領款人姓名；保留紙本簽章空間。
- 經手人、單位主管、審核人、會計、核准五格僅保留紙本空白簽核區。
- 取消勾選保留資料，未選項目的文字不列印。
- 長文字自動縮小以維持固定版面，建議簡潔填寫以保持可讀性。
- 桌面左右兩區獨立捲動；手機改為上下排列。

## 使用與列印

解壓縮後開啟 `index.html` 即可試用；建議透過 GitHub Pages 或本機 HTTP 伺服器使用，以確保瀏覽器儲存功能正常。

列印設定：A4、直式、比例 100%、邊界「無」，關閉頁首與頁尾。使用「儲存並列印」會先成功保存當下快照，才呼叫列印。金額超過原表位數、格式不正確或日期無效時，須修正才能儲存或從工具列印。

使用瀏覽器 Ctrl+P 或列印選單時，也會嘗試記錄當下內容，但瀏覽器無法等待非同步儲存或阻止其自行列印；建議優先用網站的「儲存並列印」。

## 本機紀錄與備份

- 草稿使用 `advance-request-form-v1` localStorage；紀錄庫使用 `advance-request-records-v1` IndexedDB。
- 與憑證黏存單工具使用不同資料庫及備份格式，互不覆蓋。
- 每張申請單產生臺灣日期編號；修改儲存會新增版本，未修改則沿用版本。
- 紀錄庫可搜尋全部版本的文字、依儲存日期篩選、載入修改、重新列印或刪除。
- 「開啟列印」與「確認已列印」分別記錄；關閉列印視窗不會自動判定紙張已印出。
- JSON 匯出包含所有版本、勾選、未選項目保留的文字與列印紀錄。匯入會合併，不刪除較新版本；同號不同單據會重新編號，同一版本內容衝突則整批停止。
- 資料只存目前瀏覽器，不上傳 GitHub，不跨裝置同步；清除網站資料、換瀏覽器或網址會影響資料可見性，請定期匯出備份。
- 從本機檔案移到 GitHub Pages 後是不同儲存位置，先匯出 JSON，再於新網址匯入。

## GitHub Pages 部署

建議建立公開 repository `advance-request-form`，將本資料夾內檔案放在 repository 根目錄。不要上傳使用者填寫的 JSON 備份或銀行個資。

在 Settings → Pages，Source 選 Deploy from a branch，Branch 選 `main`、`/(root)`，儲存並等待部署成功。

網站網址預期為 `https://squall021.github.io/advance-request-form/`，須在 repository 建立、程式上傳及 Pages 啟用後才可開啟。

## 開發與回復點

既有專案每一批修改前，先在 GitHub 建立指向當前 main 的獨立 `backup/YYYYMMDD-HHMMSS-before-<change>-<sha>` 分支，確認 SHA 後才修改；詳見 `AGENTS.md`。首次建立尚無舊版本，以初始提交作為後續維護基準。

本機可執行 `python -m http.server 8000`，開啟 `http://localhost:8000`。核心計算測試：`node --test tests/model.test.cjs`。

程式：`index.html`、`styles.css`、`model.js`、`app.js`、`records.js`。
